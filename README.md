# 紙幣循環台帳

個人的な紙幣収集を中心に、重複比較、余剰候補、出品、売却後の回収額を管理するスマートフォン向けMVPです。

## プライバシー設計

- 公開所蔵情報は既存の Paper Money Collection の `data/collection.json` から読取専用で同期します。
- 取得原価や売却情報などの私有データはブラウザの `localStorage` のみに保存し、外部へ送信しません。
- 取得原価、売価、取得目的などの私有情報は公開コレクションへ同期しません。
- 公開URLのランダムな名前は偶然の発見を減らすだけで、認証やアクセス制御ではありません。
- 端末の消失やブラウザデータ削除に備え、画面からJSONを書き出してください。

## データ境界

公開可能: 国・地域、発行主体、通貨、額面、発行年、カタログ番号、表裏画像、状態、解説。

非公開: 取得原価、売価、利益、購入元、取得目的、保管場所、発送情報、非公開メモ。

連携境界と将来の正本移行は [`docs/DATA_ARCHITECTURE.md`](docs/DATA_ARCHITECTURE.md) に定義しています。私有台帳の基本項目は [`data/schema.json`](data/schema.json) を参照してください。

## ローカル確認

静的ファイルだけで動作します。任意のHTTPサーバーでこのディレクトリを公開してください。

```powershell
python -m http.server 40001
```

## 現在の範囲

実装済み: 既存公開サイトとの読取同期、実所蔵数集計、紙幣登録、検索、重複一覧、当年回収額、JSONバックアップ／復元、レスポンシブ表示。

未実装: 画像保存、重複候補の精密比較、売却編集画面、認証付きクラウド同期、相場API連携、外部出品連携。AI同定や相場取得は自動確定せず、人による確認を前提とします。
